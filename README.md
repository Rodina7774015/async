├── .venv/                    # Виртуальное окружение
├── src/                      # Папка с кодом  Файл, который превращает папку src/ в Python-пакет.

Элемент	      |Простыми словами	                |Без него
.venv/	      | Отдельный ящик с инструментами	|Зависимости смешаются с системой
src/	      | Кухня для кода	    |Беспорядок в проекте
__init__.py   |Ключ от двери	    |Нельзя импортировать src
excempl.py	  |Рецепт блюда	        |Кода нет
pyproject.toml|Паспорт проекта	    |Непонятно, как собирать
uv.lock	|    Точный список покупок	|Разные версии у разных разработчиков
client (команда)	Кнопка "Пуск"	|Нужно писать длинные команды
